# PROJECT_IDEA — Автоматизация записи в клинику «Хиджама №1» (Иркутск)

Документ для AI и разработки по методологии Spec-First. Репозиторий: **hijama-no1-bot** (GitHub, публичный).

## 1. Проблема

Один мастер в клинике хиджамы «Хиджама №1» (Иркутск) ежедневно тратит **3–5 часов** на ручную переписку в Telegram:

- поиск свободных слотов;
- согласование времени;
- запрос предоплаты **500 ₽** на карту;
- подтверждения и напоминания.

Время уходит от практики. Клиенты срывают запись из‑за медленного ответа. Ручная предоплата требует постоянного контроля.

## 2. Решение

Telegram-бот автоматизирует запись:

1. Клиент пишет боту → тёплое приветствие и описание клиники «Хиджама №1».
2. Выбор свободного слота из актуального расписания.
3. Показ стоимости сеанса (**3500–6000 ₽**) и предоплата **500 ₽** через **ЮKassa**.
4. После успешной оплаты — мгновенное подтверждение записи.
5. Уведомление мастеру в личный Telegram.
6. Напоминания клиенту и мастеру: **за 2 часа** и **за 1 час** до сеанса.
7. Отмена/перенос через **админку только в Telegram** (команды/меню для мастера).

## 3. Почему сейчас

- Telegram — основной канал для клиентов в России.
- ЮKassa: API и доверие к оплате.
- Spec-First + AI ускоряют сборку одним человеком.
- Ниша хиджамы растёт; узкоспециализированных ботов мало.

## 4. Целевая аудитория

| Сегмент | Описание |
|--------|-----------|
| **Основная** | Мужчины и женщины 25–55 лет, Иркутск и область; хиджама для оздоровления и духовного очищения. |
| **Вторичная** | Клиенты по рекомендациям (мечети, знакомые, врачи). |

## 5. Архитектура

```
Клиент (Telegram) → Bot (Node.js + Telegraf)
                          ↓
                    Backend API (тот же процесс или отдельный сервис)
                          ↓
              Supabase (PostgreSQL) — слоты, записи, клиенты, платежи
                          ↓
              ЮKassa (предоплата 500 ₽ + webhook)
                          ↓
        Уведомления: мастер (Telegram) + напоминания (планировщик)
                          ↓
              Админ в Telegram (только мастер)
```

**Стек:** Node.js, Telegraf, Supabase (PostgreSQL + Auth при необходимости), ЮKassa, хостинг **Amvera**, репозиторий GitHub (приватный исходник / публичное имя репозитория **hijama-no1-bot** по договорённости).

**Будущее:** интеграция с мессенджером MAX (v2).

## 6. Монетизация

- Для клиники: предоплата **500 ₽** за запись (полная стоимость сеанса **3500–6000 ₽**).
- Перспектива: SaaS для других мастеров хиджамы.

## 7. Конкуренты

| Конкурент | Ограничение |
|-----------|-------------|
| Ручной чат | Медленно, нет автоматизации оплаты и напоминаний. |
| YClients, DIKIDI и аналоги | Сложнее, дороже, не заточены под хиджаму и одного мастера. |

**Плюс продукта:** простота, уважительный тон, предоплата, двойные напоминания под одного мастера.

## 8. План запуска

**MVP (2–3 недели):**

- Запись + предоплата ЮKassa.
- Напоминания за 2 ч и за 1 ч.
- Уведомления мастеру в реальном времени.
- Простая админка для слотов.
- Telegram + Supabase.

**v2:** MAX, история посещений, отзывы, гибче расписание.

## 9. Риски

| Риск | Вероятность | Митигация |
|------|-------------|-----------|
| Сбои ЮKassa | Средняя | Тестовый магазин + запасной способ оплаты/инструкция. |
| Срыв после предоплаты | Низкая | Правила отмены + двойные напоминания. |
| Нагрузка на сервер | Низкая | Amvera + мониторинг. |
| Клиент не понимает бота | Средняя | Простые шаги, тёплые тексты на русском. |

- Порядок работ: **Spec-First** — сначала `PROJECT_IDEA.md` и `SPECIFICATION.md`, затем код и деплой.
- Деплой: **Amvera**.
- Детальная схема БД, API, сценарии и RLS — в `SPECIFICATION.md`.
